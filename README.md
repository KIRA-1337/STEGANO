# Stegano v8 — Продвинутая LSB-стеганография

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

🔐 **Скройте данные в изображениях с профессиональным уровнем защиты**

Stegano v8 — это современный веб-инструмент для стеганографии, использующий алгоритм LSB (Least Significant Bit) с расширенными функциями безопасности и устойчивости к повреждениям.

## ✨ Возможности

### 🔒 Безопасность
- **AES-256-GCM шифрование** с случайной солью и IV
- **HMAC-SHA256** для верификации каждого блока данных
- **Plausible Deniability** — скрытый том + ложные данные для правдоподобного отрицания
- **PBKDF2** с 180,000 итераций для деривации ключа

### 🎯 Устойчивость к повреждениям
- **Majority Voting** — битовое голосование по всем областям сетки
- **Большие сетки** — до 64×64 (4096 копий данных)
- **Извлечение повреждённых данных** — максимальное восстановление даже при частичном повреждении

### 🎨 Стелс-режимы
- **Stealth LSB** — адаптивная глубина вставки (1-3 бита) в зависимости от текстуры
- **Dithering** — контролируемый шум для защиты от chi-square анализа
- **Удаление метаданных** — очистка EXIF/IPTC/XMP из контейнера

### 📊 Визуализация
- **Diff View** — карта изменений между исходным и итоговым изображением
- **Pixel Overlay** — отображение изменённых пикселей
- **Статистика** — количество изменённых пикселей, процент изменений

### 🌐 Технические особенности
- **Web Workers** — обработка криптографии в фоновом потоке
- **OffscreenCanvas** — быстрая обработка изображений
- **Адаптивный дизайн** — работает на десктопе и мобильных устройствах
- **Без установки** — работает прямо в браузере

## 🚀 Быстрый старт

### Использование

1. Откройте `index.html` в современном браузере (Chrome, Firefox, Edge)
2. **Для скрытия данных:**
   - Выберите изображение-контейнер (PNG/JPEG/WebP)
   - Введите текст или выберите файл для скрытия
   - Укажите пароль
   - Настройте параметры (бит на канал, размер сетки)
   - Нажмите "Скрыть данные"
   - Скачайте результат

3. **Для извлечения данных:**
   - Выберите изображение с данными
   - Введите пароль
   - Нажмите "Восстановить"
   - Получите скрытое сообщение или файл

### Параметры кодирования

| Параметр | Описание | Рекомендация |
|----------|----------|--------------|
| Бит на канал | Глубина вставки (1-3 бита) | LSB-1 для качества, LSB-3 для ёмкости |
| Распределение | Последовательное или PRNG | PRNG с паролем для безопасности |
| Размер сетки | Количество копий данных | 9×9 баланс, 64×64 макс. надёжность |
| AES шифрование | Шифрование перед вставкой | Всегда включено для конфиденциальных данных |

## 🔬 Как это работает

### Алгоритм внедрения

1. **Подготовка данных:**
   - Текст/файл конвертируется в байтовый массив
   - Опционально шифруется через AES-256-GCM
   - Добавляются маркеры начала/конца

2. **Распределение по сетке:**
   - Изображение делится на области N×N
   - Данные дублируются в каждую область
   - При PRNG — псевдослучайное распределение

3. **LSB вставка:**
   - Младшие значащие биты заменяются данными
   - Адаптивная глубина в зависимости от текстуры
   - Опциональный dithering для маскировки

4. **HMAC подписи:**
   - Для каждого блока вычисляется HMAC
   - Позволяет точно определить повреждённые блоки

### Алгоритм извлечения

1. Чтение всех областей сетки
2. Верификация HMAC для каждого блока
3. Majority voting для восстановления битов
4. Дешифровка AES (если применено)
5. Извлечение оригинальных данных

## 🛡️ Безопасность

### Криптография
- **AES-256-GCM** — authenticated encryption
- **PBKDF2-SHA256** — 180,000 итераций
- **HMAC-SHA256** — целостность блоков
- **Crypto.getRandomValues()** — криптографически стойкий ГСЧ

### Защита от анализа
- Chi-square атака → mitigated dithering'ом
- RS analysis → adaptive depth
- Visual attacks → LSB-1 в гладких областях

### Plausible Deniability
При включённом режиме создаются два тома:
- **Скрытый том** — реальные данные (основной пароль)
- **Ложный том** — безобидный контент (ложный пароль)

Это позволяет правдоподобно отрицать наличие секретных данных.

## 📝 Примеры использования

### Скрытие текста
```
1. Контейнер: photo.png (1920×1080)
2. Сообщение: "Secret message here"
3. Пароль: "mySecretPassword123"
4. Параметры: LSB-1, 9×9 сетка, AES включён
5. Результат: photo_encoded.png
```

### Скрытие файла
```
1. Контейнер: landscape.jpg
2. Файл: document.pdf (500 KB)
3. Параметры: LSB-2, 25×25 сетка, HMAC включён
4. Требуемый размер контейнера: ~2 MPix минимум
```

### Максимальная надёжность
```
1. Контейнер: high_res.png (4K+)
2. Параметры: LSB-1, 64×64 сетка (4096 копий)
3. Дополнительно: dithering, stealth mode
4. Выдерживает до ~99% повреждений областей
```

## ⚠️ Ограничения

- **Ёмкость:** зависит от размера изображения и параметров
  - LSB-1, 9×9: ~0.3% от размера контейнера
  - LSB-3, 64×64: ~3% от размера контейнера
  
- **Форматы:** PNG рекомендуется (без потерь)
  - JPEG возможна, но снижает надёжность из-за компрессии
  
- **Производительность:** большие сетки требуют времени
  - 64×64 сетка: ~5-10 секунд на кодирование
